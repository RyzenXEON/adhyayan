# 📚 Adhyayan

Adhyayan is a learning resource and virtual classroom app designed to make quality education accessible to students in rural India. Built with Flutter and powered by AWS services, cloud-based learning resources, and real-time virtual classrooms using ZeGo Cloud real-time voice, video & chat functionality. Students can access subject-specific study materials, attend live classes, and connect with teachers seamlessly, even in low-resource environments. With support for regional needs, affordable scalability, and a user-friendly interface, Adhyayan bridges the educational gap and empowers students with equal learning opportunities.

---

## 🚀 Features
- 📖 Learning Resources – Access subject-wise PDFs, notes, and materials stored securely in AWS S3.
- 🎥 Virtual Classroom – Real-time interactive classes powered by WebRTC for seamless video/audio sessions.
- ⚡ Fast & Scalable – AWS Amplify + Lambda ensure smooth, scalable, and cost-effective app performance.
- 🏫 Student & School Profiles – Store and manage student, teacher, and school information in DynamoDB.
- 🌐 Multi-Language Support – Content tailored for local languages to make learning inclusive.
- 🤝 Teacher Empowerment – Virtual tools for rural educators to teach and guide students effectively.
- ⚙️ Modular codebase for easy extension

---

## 🛠️ Tech Stack
- **Flutter (Dart)** – Core framework
- **AWS Lambda** - API Backend
- **DynamoDB** – Database of Choice
- **API Gateway** – Handle API Calls
- **ZeGo Cloud** - Real-time Voice, Video & Chat API
